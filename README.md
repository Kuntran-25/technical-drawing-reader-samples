# Technical Drawing Reader: sample drawings

Synthetic example drawings of machined parts, used as demo input for the
Technical Drawing Reader Actor on Apify. They don't show real parts or real companies.

- `samples/sample-bushing.pdf`: bearing bushing (vector PDF)
- `samples/sample-shaft.pdf`: drive shaft (vector PDF)
- `samples/sample-bushing-scan.png`: the bushing as a scanned image
